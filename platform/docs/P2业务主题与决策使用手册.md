# 能源业务主题与决策使用手册（P2）

本版用于和开发团队、甲方共同检查“研究什么、为什么属于能源电力、数据说明什么、下一步做什么”。入口是明确的能源业务任务，原 F0001—F0500 保留为算法聚类追溯编号。

可直接打开 [本地交互预览](../preview/index.html)，或者查看 [业务主题与决策解读工作簿](../assets/p2/业务主题与决策解读.xlsx)。本地预览使用实际交付数据，不需要网络服务；它尚未替换甲方已经部署的界面。

## 概念和模块职责

| 概念 | 本版含义 | 用途 |
|---|---|---|
| 原始记录 | 一篇论文/预印本、一条去重申请记录或一份政策文本 | 追溯研究与数字来源 |
| F 算法聚类 | 原关键词模型形成的集合，允许混杂 | 保留历史编号、检查组成，不能直接视为业务分类 |
| 业务分类 | 新能源发电、电网运行、输配电、储能、氢能与燃料、终端用能、常规能源与核能、低碳环保、能源市场与政策九类 | 帮助用户按实际工作任务浏览 |
| 业务主题 | 51 个有明确研究对象、纳入条件和决策问题的检索范围 | 汇总同一任务的文献并跟踪变化；允许多归属 |
| 具体技术对象 | 同一配置、用途、证据期间的产品或项目 | 解释 TRL/CRL、制定测试和尽调问题 |
| 定性分析框架 | 逐业务编写的决策问题、待验证瓶颈、应用检查项 | 指导研读与验证；不是已经证实的市场机会 |

材料、算法、设备、经济政策属于不同研究内容类型。经济政策可以直接服务电力市场、能源投资和用户成本分析，无需改名为技术；经济政策主题不获得 TRL/CRL 等级。

## 怎么使用

1. 在“能源业务主题”选择业务分类或搜索，例如“构网”“电力市场”。先看研究对象和决策问题，确认是否符合自己的任务。
2. 看趋势判断、同期份额与季度数量，再看建议开展哪类研究核查。近期统一为 2025-07-01—2026-06-30；前期为 2024-07-01—2025-06-30。
3. 展开代表证据，核对题名命中、日期、原文片段和来源。样本按固定散列抽取，不按关键词模型最高分挑选；样本不是整个主题。
4. 对有具体对象的主题，进入对象卡，查看配置、场景、技术/商业证据及下一步核查清单。关联目前是对象文本候选，必须核对对象边界。
5. 用“F 编号追溯”查看旧编号的实际业务构成；未命中记录仍待补充判断。

## 分类做了什么

本版扫描冻结语料的 5,119,004 条记录，使用**题名中的明确业务对象和任务**筛选；不会因原始关键词写着 Business、Porosity 或 Probabilistic logic 就认定其属于某能源业务。

51 个主题合计命中 1,043,464 条去重记录，其中论文/预印本 975,638 条、专利申请记录 65,683 条、政策 2,143 条。多标签成员关系为 1,105,686 条，不能当作去重文献数。上述命中数包含所有年份；趋势统计另外排除不可用、撤稿和模板记录，并使用固定窗口。

全部记录都进入了筛选，但只有约 20.4% 命中当前较明确的题名范围。**其余记录并未被判为能源无关。** 它们可能使用其他语言或缩写、只在摘要中说明用途，或属于尚未定义的能源任务。下一轮应补充这些范围与语义审核，不能直接把未命中记录删除。

本版在主统计中只使用题名，避免把摘要的背景应用或参考方法当成研究对象。该选择仍可能误命中或漏召回，属于可复现检索范围，不是已验证的全行业语义分类。完成 102 条助手题名开发审阅，记录了 10 条明确需要移出当时检索范围的样本，并据此收紧规则；这批样本用于改进规则，不能充当独立准确率测试。

## F0001、F0022 应怎么解释

F0001 原有 11,311 篇论文，本版有 1,690 篇命中明确业务任务，包括燃料电池、锂离子电池、碳捕集、制氢等；其余 9,621 篇继续等待判断。不能把整个 F0001 改叫“储能材料”。

F0022 原有 30,150 篇论文，其中 1,493 篇命中本版业务范围，涵盖多种能源任务。明确的电力市场制度记录进入电力市场主题，110kV 变压器保护记录进入设备主题；制服规定等未命中任何能源业务。不能给全部 F0022 冠以“能源经济与政策”名称。

F0110 同样保留混合聚类身份。新的“新能源功率与负荷预测”G01 跨原 F 聚类逐篇检索，近期 2,623 篇、前期 2,000 篇，但相对整个冻结文献池的份额仅为前期约 1.06 倍，当前标为相对平稳。原 F0110 的 2.78 倍描述的是另一个集合，不能直接沿用，也不能把这两个比值当成同一集合清洗前后的严格对照。

## 趋势、潜力与行动

本版重新计算每个业务主题 20 个完整季度的论文数、同比份额、机构名称去重数，以及按来源分别统计的记录数。分母是同期冻结语料中质量合格的去重论文总数，不是各业务主题计数的总和，也不是全球能源领域的完整论文规模。

| 信号 | 规则 | 对甲方的用途 |
|---|---|---|
| 样本较少或基期较小 | 近期或前期不足 30 篇 | 补充代表证据，避免小基数放大 |
| 份额持续上升 | 份额比至少 1.2、至少 3 个季度同比上升、机构数增加 | 优先研读增量文献、比较关键验证条件、安排技术交流 |
| 份额上升但持续性待观察 | 份额比至少 1.2，其他条件不足 | 保持跟踪，继续观察季度持续性 |
| 份额下降 | 份额比小于 0.8，且两期样本充分 | 核查术语迁移、收录和技术路线变化 |
| 份额相对平稳 | 其余样本充分情形 | 根据应用需求和实测证据决定跟踪优先级 |

这些阈值是透明的工作筛选规则，不是经过预测验证的统计模型，未输出置信度或未来成功概率。没有强制生成正式热点排行榜。

例如，构网型变流近期 1,016 篇、前期 645 篇，份额约 1.27 倍；虚拟电厂近期 497 篇、前期 313 篇，份额约 1.28 倍，两者当前均出现持续上升信号。建议分别核查弱网/限流/多机测试，以及聚合资源的可交付调节能力和实际结算。不能仅凭文献增长认定技术成熟或商业回报良好。

潜力解读拆成“已经观察到的研究信号—待核查机会—具体瓶颈—验证行动”。瓶颈属于分析框架，不能写成已经对所有方案证实的共同缺陷。论文数不是研究人员数；机构按归一化名称统计，不是严格机构 ID。专利为申请记录而非全球专利族，政策题名命中不等于政策支持。

## TRL/CRL 能辅助什么决策

本版沿用既有对象公开证据初评，不新增或抬高等级。122 个对象均增加了对象配置和应用场景对应的行动说明，38 个对象获得明确文本命中的业务关联候选；其余对象仍可在对象页单独查询。

| 对象证据阶段 | 可开展的行动 | 仍需什么 |
|---|---|---|
| 技术轴未知 | 核查设计与验证材料 | 同对象、同配置的技术测试 |
| TRL1—4 | 安排概念或目标工况验证 | 实验条件、性能、可重复性与风险 |
| TRL5—6 | 评估示范测试条件 | 原型尺度、现场边界、验收指标 |
| TRL7—9，商业轴未知或 CRL1—2 | 核查工程适配和商业履约 | 客户、试用、合同、交付结算 |
| TRL7—9 且 CRL3 或以上 | 开展复制应用与经济性尽调 | 重复交付、运维、持续收益和甲方工况 |

TRL/CRL 两轴独立。TRL3 在本项目中是理论可行性验证；CRL4 表示规模化商业应用。若出现 TRL3/CRL4，应核查配置、场景和时期是否一致，不能直接称技术成熟。当前只有 13 个对象双轴均已知，99 个 CRL 未知；本次没有新增外部商业证据。未知不等于最低等级，主题不按对象均值或最大值评级。

## 尚未完成的事项

- 当前成员是自动题名筛选，尚未完成全量语义审定和独立专家验收；其他语言、隐含用途与目录外能源任务仍需覆盖。
- 机构使用现有元数据，尚无作者人数趋势；专题文献增加的技术或政策原因还需要逐篇综合研究。
- 应用与商业证据没有扩充，不能从论文增长推出商业成熟或未来收益。
- 预览是可用的本地联调页面；实际生产前端仍需开发团队接入本版数据。
