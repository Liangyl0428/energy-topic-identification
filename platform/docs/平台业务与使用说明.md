# 平台业务与使用说明

> 本文描述 P0/P1 契约。当前业务展示优先采用 [P2 使用手册](P2业务主题与决策使用手册.md)及 [P2 接口说明](P2接口与复现说明.md)；原 F500 和 P1 字段继续保留。

平台帮助使用者从研究文献中发现值得核查的方向，并进一步查看具体技术对象已有的工程和商业证据。当前交付增加了业务解释与证据接口；原有算法主题仍待范围审核，数值候选不能直接作为采购或投资结论。

## 五个概念

| 概念 | 是什么 | 可以做什么 |
|---|---|---|
| 原始记录 | 一篇论文、一件专利、一份政策或一条项目证据 | 查看数字和判断的来源 |
| 算法主题 | F0001 等由关键词模型聚合的文献集合 | 组织检索、发现内容关联和研究信号 |
| 业务分类 | 储能、电网运行、能源市场与政策等九类导航 | 按甲方关心的任务寻找信息；允许多归属 |
| 技术方向/业务子主题 | 锂金属电池界面、风电功率预测等明确任务 | 跟踪路线；必须有独立的纳入、排除范围 |
| 评价对象 | 特定配置、场景、期间的产品或项目 | 进行 TRL/CRL 公开证据初评 |

“材料、算法、设备、系统、资源、经济政策”是研究内容类型，与业务分类分开。例如，锂金属电池界面属于储能业务、材料类型；电力市场机制属于能源市场与政策业务、经济政策类型。

## 使用路径

1. 从业务分类或 F 编号进入主题，先查看定义、纳入范围、排除范围和审核状态。部分主题目前仅有待审占位说明。
2. 查看趋势卡中的判断、关键数字和时间窗口，再打开证据表核对。趋势描述针对原算法聚类；新业务子主题的样本统计单独展示。
3. 查看代表文献和被排除、暂缓的记录，确认它们是否符合自己的业务需求。题名能支持狭义任务归类，但不能证明研究有效、工程可用或已经商业化。
4. 如有关联案例，查看对象配置、用途、证据期间和两轴结果。对象与主题的关联目前也是候选，需要核查。
5. 将对象卡中的待核查门槛转成下一步测试、技术交流或尽调清单，再结合本地工况和经济性作决策。

## 三个主题样例

**F0001：多孔材料与界面传输。** 该聚类同时包含锂金属电池界面、光热熔盐腐蚀、冷却材料、环境颗粒迁移和肿瘤治疗。当前逐篇审核把有明确用途的两条记录归入储能/光热相关子主题；肿瘤治疗等移出本轮能源范围。只有“冷却”或“碘捕集”题名、缺少具体能源用途的记录暂缓。不能把整个 F0001 当作储能材料。

**F0022：经济与工程混合聚类。** 电力市场机制可以是能源经济研究；110kV 变压器保护则应进入输配电业务，热电材料进入能量转换研究。当前原聚类近期论文从 1,844 篇变为 327 篇，份额为前期约 14.4%。这支持“该算法聚类近期份额下降”的提示，不能推出能源经济领域衰退。

**F0110：概率方法与能源预测。** 原聚类近期论文从 470 篇变为 1,612 篇，份额为前期约 2.78 倍，4 个季度的份额均同比增长，参与机构从 573 家变为 1,534 家。这是值得优先核查的研究信号。样例中确有风电功率和电动汽车充电负荷预测，也有考古学文本和不同任务的变电站设计。应先核查和拆分任务，再形成能源业务热点判断。

以上近期窗口为 **2025-07-01 至 2026-06-30**，前期为 **2024-07-01 至 2025-06-30**。论文增加表示研究产出增加，机构增加表示参与机构扩大；本交付没有作者人数增长统计，也没有未来发展预测。

## 如何理解成熟度

TRL 表示技术验证证据所支持的阶段，CRL 表示商业活动证据所支持的阶段，两轴独立。项目采用 Q/GDW 12566—2025 的 TRL 定义及项目五级 CRL 规则。

| 显示内容 | 当前能说明什么 | 下一步 |
|---|---|---|
| TRL4、CRL未知 | 有实验环境验证证据，商业材料不足 | 补部件集成/模拟工况测试；核查客户、试用及实际合同 |
| TRL6、CRL2 | 有原型验证与市场探索证据 | 核查工程测试条件及商业履约 |
| TRL9、CRL3 | 有产品工程应用及早期商业履约证据 | 核查重复交付、运维能力、持续经济性及本地适配 |
| 某轴未知 | 尚无足够材料支持该轴等级 | 按对象卡缺口补材料；不能填成 0 或最低等级 |

实际联调样例包含低压配电网在线电压调节对象（C0540-N01，TRL6/CRL2）、WindFloat Atlantic 三台浮式平台（W001，TRL9/CRL3）和 Hornsdale 一期储能调频系统（W014，TRL9/CRL3）。这些对象保留各自实际的候选主题关联，不强行关联到 F0001、F0022、F0110。

TRL3 在本项目中是“理论可行性验证”。CRL4 是“规模化商业应用”，需要重复交付、供应/运维能力及持续商业经济性。若同对象出现 TRL3/CRL4，应先核对配置和期间、补齐技术材料，不能统称技术成熟。当前数据只有 CRL2、CRL3，没有 CRL4 案例。

成熟度证据截止日为 **2026-09-25**，不是今天的产品状态。122 个对象中只有 13 个双轴都已知，所有结果都是公开证据初评；正式等级为空。

## 本轮覆盖和待办

本轮可交付 500 张原聚类趋势卡、122 张对象解读卡和 500 个主题的候选案例分布接口。其中 **3 个主题有详细业务说明，其余 497 个只有明确的待审占位字段**。3 个重点主题采用此前按 NMF 分数选取的 24 条诊断记录，属于定向样本：11 条纳入、6 条范围外、7 条待补证据。这里的“审核”是助手依据本地文本作出的初审，尚无独立领域专家批准。

新建的 11 个业务子主题只包含这 11 条已纳入记录，并已按真实成员重算窗口计数与机构去重数。定向样本不能估计全部主题的误分率、增长率或排名，因此这些字段为空。全量业务热点尚需完成成员筛选后重算。

可直接打开 [P1 审阅工作簿](../assets/p1/P1_review.xlsx) 查看结果；开发联调使用 [六组完整样例](../assets/p1/platform_examples.json)。数据口径见 [数据与指标字典](数据与指标字典.md)，接入方式见 [模块接口与展示规范](模块接口与展示规范.md)。
