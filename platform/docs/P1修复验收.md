# P1 修复与验收

本轮将业务说明、范围初审、趋势洞察和对象行动建议接入原有三个模块。修改的是可运行代码、可导入的数据接口和使用文档；没有重新开展算法对比实验。原算法主题、原热点数值和 P0 修复后的成熟度结果保持一致。

## 典型问题的处理结果

- F0001 的骨肉瘤治疗记录保留原始身份，但移出本轮能源业务样本；锂金属电池界面与光热熔盐腐蚀分别进入有明确任务的子主题。
- F0022 中的 110kV 变压器保护、电力市场制度和热电材料分别归类。没有将全部 F0022 改称能源经济。
- F0110 的风电功率预测、充电负荷预测、变电站设计和工业空气需求预测分别记录；考古记录列为范围外。仅题名的气温异常预测暂缓，未直接当作无关。
- F0022 的份额下降与 F0110 的升温使用不同判断；原始数字均绑定来源表和行键。研究产出/机构扩张没有被写成研究人员增长。
- TRL3/CRL4 的组合处理要求核对同对象配置、场景和期间，不解释为技术成熟。未知轴保留 null，不降低为 0 或 CRL1。

## 验证与复现

入口：`python final/tools/build_p1.py`。构建只用交付内的本地快照和已有汇总表，不需外部大模型或重新训练。输入与代码指纹见 [BUILD.json](../assets/p1/BUILD.json)。

回归检查覆盖来源引用、F0022 错配分流、证据不足的保留、样本重算、数值叙述、两轴类型与判级一致性、跨对象误引防护、主题分布和原 P0 输出保持性。执行结果见 [P1_TESTS.xml](../provenance/P1_TESTS.xml)，完整文件、版本及文档引用检查见 [P1_VALIDATION.json](../provenance/P1_VALIDATION.json)。

本轮保留 P0 验收文件的原记录。P1 前状态备份在项目 `work/p1_repair_20261018/before/`，固定数值指纹另随交付保存于 [P1_BASELINE.json](../provenance/P1_BASELINE.json)。新的现行文件指纹见 [P1_FILES.json](../provenance/P1_FILES.json)。

## 尚未完成的业务工作

当前不是 500 个主题已完成能源业务化改造。三个重点主题尚需跨年份、分类差距及来源的分层补审，并筛选全量成员；其余 497 个主题需要详细业务定义和文献审核。之后才能计算正式业务主题的领域份额、机构统计和热点排名。完整主题范围与对象关联也仍需领域负责人核查。

当前“完成混杂处理”仅指已审的 24 条诊断记录已逐条留下去向和依据；原全量 F500 分类没有被静默改写。代码强制将样本趋势/排名留空，防止把部分审阅当成全量结论。工程和商业证据扩充、作者人数趋势与未来预测验证仍属于后续工作。
