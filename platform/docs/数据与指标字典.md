## 数据批次与时间口径

| 数据/模块 | 当前实际范围 | 使用限制 |
|---|---|---|

| 论文来源日期 | 2000-01-01—2026-08-31 | 包含期刊论文/预印本合并后的 work 身份；不是只取热点窗口 |
| 专利来源日期 | 2026-01-01—2026-08-31 | 本地可用公开记录，按国家/申请去重；不能推出多年专利增长 |
| 政策来源日期 | 1993-08-04—2026-09-23 | 包含多种政策/行政文本；相似关联不等于同任务支持 |

| 热点历史 | 2021Q3—2026Q2，即 2021-07-01—2026-06-30 | 20 个完整季度，不能写成截至今天 |
| 核心窗口 | 2023-07-01—2026-06-30 | 三年统计 |

| 跨来源共同窗口 | 2026-01-01—2026-06-30 | 论文/专利份额可比窗口；不是全部来源累计计数 |
| 成熟度评估截止日 | 2026-09-25 | 有界对象的公开证据初评；证据可知日期也需要满足截止日 |

来源日期范围摘自冻结语料 `INPUT_MANIFEST.json`，不是重新扫描原始文件得到的今天的数据。热点摘要中的 `papers_used_for_hotspot_windows=4,740,374` 是合格且不晚于截止日的论文池；实际季度网格再从 2021-07-01 起聚合，不能把这个池总数当作近五年论文量。

成熟度 `data/dataset.json` 保留证据采集时的来源上下文，其中主题数、分配数量不是当前 F500 目录口径。当前主题数为 500；当前分配数量从主题发现摘要读取。不要将来源上下文中的 750 或旧分配数拼接进当前平台统计。

## 主键与关联

| 字段 | 含义与约束 |
|---|---|
| `doc_id` | 原始文献身份键，跨论文/专利/政策带来源前缀 |
| `row_id` | 冻结语料内部行键；只能在同一快照内使用 |
| `topic_id` | 当前模型内部整数主题索引；不是业务概念 ID |
| `category_id` | 当前 `F0001`—`F0500` 主题编号；三个模块按此关联 |
| `category_name` | 从当前主题主表按 `category_id` 关联的名称；当前仍是算法关键词名称 |
| `category_ids` | 当前主关联主题列表。CSV 为 JSON 数组字符串，JSON 为数组；Top3 候选另见 `theme_context_top3.csv` |
| `taxonomy_version` | 当前目录版本 `full_nmf500_20260926` |
| `case_id` | 唯一成熟度评价对象，不等同主题、技术方向或文献 |
| `legacy_category_id/name/ids` | 修复或映射前的历史上下文，只用于追溯，不参与当前主题关联 |

主题主表是 `energy-topic-identification/assets/full_nmf500/topic_catalog.csv`，名称列为 `name`。主题—对象关联仍是相似检索候选，`mapping_needs_review=true`，名称同步不代表语义审核完成。不要把对象的等级转移给整个主题。

## 成熟度字段契约

输出：`energy-technology-trl-crl/assets/full_nmf500/case_hotspot_links.csv` 及同名 JSON。

| 字段 | 类型 | 定义 |
|---|---|---|
| `trl_public_evidence_stage` | 整数 1—9 或 null | 原评估引擎支持的 TRL 初评等级 |
| `crl_public_evidence_stage` | 整数 1—5 或 null | 原评估引擎支持的 CRL 初评等级 |
| `trl/crl_evidence_status` | `supported/unknown/conflict` | 分别表示存在受支持等级、尚不能支持等级、无可支持等级且有未解决冲突 |
| `trl/crl_has_conflict` | boolean | 任一已检查门槛是否存在有效冲突；更高阶段冲突不自动抹掉已支持的较低等级 |
| `trl/crl_stage_name` | string 或 null | 来自本项目 `trl_crl/rules.py` 的阶段名称 |
| `trl/crl_missing_evidence` | string | 对象已有缺口记录的相关内容；关键词仅用于归置解释，不用于判级 |
| `trl/crl_explanation` | string | 阶段或未知状态的含义与适用边界 |
| `trl/crl_display` | string | 如 `TRL4｜实验环境验证`、`CRL未知｜证据不足`；不能用于计算 |
| `paired_axes_usable` | boolean | 同一对象的两轴均非 null，可进入双轴图 |
| `formal_trl/formal_crl/current_industry_level` | null | 本交付不宣称正式评定或整个行业等级 |
| `assessment_status` | string | 当前为 `public_evidence_preassessment` |
| `maturity_rules_version` | string | 使用的现有判据版本；本次未修改量表或评分规则 |
| `assessment_cutoff/evidence_period/object_configuration` | string | 评估截止日、证据期间及对象配置，展示时应随等级保留 |

CSV 没有原生 null 类型：等级空单元格表示未知，已知等级为 `4` 这样的整数文本，不再写 `TRL4` 或中文原因。JSON 使用真正的整数/null。前端不得把空字符串/null 转成 0；也不得以未知数量推断技术落后。

```python
frame = pandas.read_csv(path, dtype={
    'trl_public_evidence_stage': 'Int64',
    'crl_public_evidence_stage': 'Int64',
})
unknown_crl = frame[frame.crl_public_evidence_stage.isna()]
scatter = frame.dropna(subset=[
    'trl_public_evidence_stage', 'crl_public_evidence_stage',
])
```

当前有 122 个对象：TRL 已知 108、未知 14；CRL 已知 23、未知 99；双轴已知 13，双轴未知 4。正式等级数仍为 0。

本项目采用 Q/GDW 12566—2025 的 TRL 定义及项目五级 CRL 规则。TRL3 为理论可行性验证；CRL4 为规模化商业应用，需要重复交付、供应/运维能力和经济性证据。两轴相互独立，不能将“TRL3、CRL4”概括为技术成熟。当前证据只有 CRL2、CRL3，没有 CRL4 案例。

## 分类和热点字段

| 文件/字段 | 定义与展示要求 |
|---|---|
| `topic_catalog.csv: domain/analysis_scope` | 当前主题范围待审核；不是已确认能源业务分类 |
| `assignment_status` | 记录已分配、不可用或缺关键词等状态，保留未分配记录 |
| `nmf_relative_top1/margin` | NMF 相对贡献与差距，不是正确归类概率 |
| `topic_1_cosine/top1_top2_margin` | 语义相似度及候选差距，不是政策支持或成熟度证据 |
| `hotspot_metrics.csv: core_score/emerging_score` | 现有评分程序的相对研究信号，不能解释成投资回报概率 |
| `core_numeric_candidate/emerging_numeric_candidate` | 数值门槛候选；当前分别 287、119 个，未自动完成范围审核 |
| `core_scope_approved/emerging_scope_approved` | 主题范围审核状态，必须与数值候选区分 |
| `quarter_counts.csv: period/papers` | 固定季度内论文计数，用于重建份额和趋势 |
| `institution_citation_context.csv` | 机构名称归一后的去重计数、按发表年份归一的累计引用背景；机构数不是作者人数 |
| `cross_source_signals.csv` | 全来源关联数与 2026H1 共同窗口的关联数分开；政策支持和申请人多样性尚未核验 |
| `theme_evidence_profiles.csv: theme_trl/theme_crl` | 始终留空，主题不能由案例均值/最大值获得等级 |

更细的公式与门槛沿用各模块方法文档。P1 保留原 F500 的成员和热点数值，另建带版本的业务样本成员并重算计数。新样本统计不继承原主题的份额、分数或排名；完整业务成员筛选后才能重算全量业务热点。


## P1 业务解释字段

输出目录为各模块 `assets/full_nmf500/p1/`，完整路径和连接示例见 [模块接口与展示规范](模块接口与展示规范.md)。

| 字段 | 类型与含义 |
|---|---|
| `business_version` | string，本轮为 energy_business_p1_20261018；独立于算法目录版本 |
| `display_name_zh/definition` | 中文业务说明；尚未审核的 497 个主题明确标为占位，不算完成命名 |
| `business_categories/content_types` | string 数组，分别表示业务方向与内容类型；可多选 |
| `business_categories_basis` | 目前是已纳入诊断文献的归属依据，不代表整个 F 主题 |
| `business_topic_id` | 有明确纳入/排除定义的业务子主题主键；不等于 F 编号 |
| `review_status/reviewer_id/reviewer_type` | 审核状态与参与者；助手初审不等于独立专家批准 |
| `decision` | include / outside_current_energy_scope / insufficient_evidence；证据不足不等于无关 |
| `quote_field/quote` | 题名或正文中的连续原文片段；以 scope_evidence 同 doc_id 文本核验 |
| `membership_scope/population_scope` | 明确统计人群：诊断已审子集或原算法聚类，不能混用 |
| `rank_eligible/scope_approved` | boolean；本轮全部 false |
| `judgment/key_numbers/narrative` | 由原表数值产生的判断、事实与文字，数字字段可回到 evidence_refs 所列记录 |
| `weight_sensitivity` | 权重扰动下的排名分位数，不是统计置信区间 |
| `recommended_actions/limitations` | string 数组，行动与使用限制需随结论展示 |
| `generation_method/model/prompt_version` | 本轮为确定性模板；无外部模型，后两项为 null |
| `future_potential_score` | null；没有验证未来预测，不制造潜力分 |
| `sampling_denominator` | 24 条定向诊断样本；不是全量领域论文分母，不能计算行业份额 |
| `institution_metadata_missing` | 未匹配元数据的成员数；缺元数据时不能把机构数解释成完整覆盖 |
| `institution_names_empty` | 已审成员中没有机构名的数量；去重机构数仅覆盖已有记录 |
| `hotspot_eligible` | 原样本 usable，且元数据存在、非撤稿/模板；窗口另外筛选 |
| `trl/crl_next_stage_to_investigate` | 待核查的相邻阶段；未知轴或已到量表最高阶段为 null，不是预测等级 |
| `trl/crl_evidence_gap_requirements` | 门槛 ID、等级、要求和状态；unknown 是未核实，不等于实际失败 |
| `trl/crl_supported_gate_ids` | 支持当前公开证据等级的门槛 ID，连接 gate_evidence |
| `joint_interpretation` | 同对象两轴的组合解读，保留配置、期间和证据边界 |
| `trl_distribution/crl_distribution` | 关联对象等级到计数的映射，unknown 计数单列；空对象集合用空字典 |

新业务统计按冻结 doc_id 去重；日期边界包含首尾两天；机构按原热点模块的分号拆分、去首尾空格、转小写规则去重，不是标准机构 ID，也不是作者人数。11 条纳入记录目前各有一个业务子主题；未来允许多归属时，跨主题汇总须重新按 doc_id 去重。
