# P2 接口与复现说明

业务层版本 `energy_business_p2_20261019`。原 F500 分类版本不变。主导航使用 `business_topic_id`，F 编号用于追溯；不要把两者等同，或直接把旧 F 主题的增长率搬到新业务主题。

## 入口与模块文件

| 文件（相对 final） | 主键与作用 |
|---|---|
| assets/p2/platform_data.json | 联调聚合包：summary、categories、topics、legacy_topics、cases、evidence_samples |
| energy-topic-identification/assets/full_nmf500/p2/business_taxonomy.json | business_topic_id；51 个业务定义、题名条件、决策问题与瓶颈 |

| 同目录 f_topic_bridge.json | category_id；500 个 F 主题的任务构成、去重命中数和待判断数量 |

| 同目录 business_quarter_counts.csv | business_topic_id + period；20 季度计数及分母 |
| 同目录 population_quarter_counts.csv | period；同期去重质量合格论文总数 |
| 同目录 source_counts.csv | business_topic_id + source；全量和 2026H1 共同窗口计数 |

## 筛选及统计契约

- 输入来自 `config/runtime_paths.json` 指定的冻结分类结果，遍历 259 个文件、5,119,004 条记录。输入分片本次重新计算 SHA256；原始 CSV、冻结正文全分片和大型元数据库没有本次全量重哈希。
- 名称和说明由本轮明确编写的能源任务定义提供；分类用原始题名的 AND 正则条件与排除条件，不读取原始 Business 等关键词作业务判断。
- 保留多标签。逐业务成员唯一键为 `(doc_id,business_topic_id)`；跨业务汇总必须重新按 doc_id 去重。
- 未命中属于 `unresolved`，不是 `outside_energy`。撤稿、模板和不可用记录仍计入输入总量，窗口论文统计使用 `usable AND NOT retracted AND NOT template_record`。
- 分母含同期所有上述合格论文，包括原 F 分类未分配但有可用文本的论文；因此本版分母与原 F500 分母不保证相同。它表示冻结文献池份额，不表示全球行业份额。
- 对每个季度及两期窗口分别求分子、分母。`share_growth_ratio=(recent_papers/recent_denominator)/(previous_papers/previous_denominator)`；前期为零时 null，不填无穷大或人为伪计数。
- 机构去重继承现有元数据库的名称拆分规则；`metadata_coverage` 分别给出近两年匹配缺失与空机构记录。机构名不是人员 ID。
- 来源分别统计：专利不参与论文增长率；政策相关不代表支持。来源迁移未被当成成熟度证据。
- `potential_assessment` 是事实、机会问题、验证条件和下一步行动的组合，不是未来概率。`scope_approved`、`rank_eligible` 当前全部 false；这些状态不阻止展示明确标识的检索范围趋势。
- 成熟度继承 P1 真实整数/null；`business_links` 引用对象字段的实际命中片段，候选不能自动获得人工批准。主题无标量 TRL/CRL。

## 数据追溯

完整逐文献成员表在项目的 `work/business_p2_20261019/memberships.parquet`，轻量数据库在同目录 `business.duckdb`。交付摘要保存成员文件哈希。成员以 doc_id 和 row_id 连接冻结正文，F 编号继续保留。生成这些大文件需要项目外于 final 的数据路径；复制 final 只能查看紧凑交付与预览，不能假定具备全量重算输入。

`evidence_samples.json` 包含 696 条主题—文献样本关系，678 个去重文献。每个业务主题在近期、前期、其他年份、专利和政策层分别按固定 MD5 最小值取至多 3 条；稀缺层不足 3 条则全取。分层不是总体随机抽样，不能合并估计准确率或误分率。正文片段最多 1,800 字符，`body_excerpt_truncated` 标明是否截断；主筛选始终只看题名。

开发题名审阅位于 `energy-topic-identification/data/business_v2/development_title_review.json`。102 条记录为助手对题名的审阅，10 条发现的误命中用于修正规则；它不具备独立专家或独立测试集地位。P1 原有 24 条逐篇初审继续保留。

## 构建和验证

在项目根目录执行，使用已有本地环境：

```bash
.venv-hotspots/bin/python final/tools/build_p2.py
.venv-hotspots/bin/python final/tools/build_p2_preview.py
.venv-hotspots/bin/python -m pytest final/tests/test_p2_delivery.py final/tests/test_p1_delivery.py -q --import-mode=importlib -p no:cacheprovider --junitxml=final/provenance/P2_TESTS.xml
node final/tools/check_p2_preview.cjs
.venv-hotspots/bin/python final/tools/refresh_p1_manifests.py
.venv-hotspots/bin/python final/tools/validate_p1.py
.venv-hotspots/bin/python final/tools/validate_p2.py --refresh
```

浏览器检查需要已有 Playwright 与 Chrome；脚本允许通过环境变量指定路径，禁止联网安装。计算不调用外部模型或发送文献。重算缓存绑定题名规则、成员生成逻辑与输入分片指纹；`--force` 强制重建成员。元数据变化会重新计算机构统计；不复用旧派生趋势。

业务定义维护在 `tools/p2_taxonomy.py`。调整边界应建立新的业务版本，并对旧样本之外的新样本检查；不能靠改审核状态或重写指纹冒充专家批准。正式接口接入时保留版本、窗口、原始证据和候选标识。

## 页面接入建议

主题页依次显示：业务对象和决策问题、已观察的趋势、任务相关瓶颈及行动、代表文献、候选关联对象。研究信号与商业判断分别展示；不默认绘制只有单轴的对象，不把未知轴转成 0。

F 追溯页显示原算法名称、逐篇业务组成与待判断数量；不沿用学科名称作为业务导航，不让同一文献在汇总时重复计数。经济政策主题解释制度、价格或投资问题，不显示主题成熟度。
