关键词词典与论文多主题归类

版本：keyword_dictionary_multilabel_20261019。根据本库实际词汇，由助手整理主题和触发词，再按明确规则匹配论文。主题词可编辑、每条归属可追溯；这是一版受控词典分类结果，尚未经专家审定。

当前结果

处理 4,831,088 篇论文，48,329 个原始关键词ID，合并明确同义词后 48,327 条。共 71 个主题；1,806,658 篇命中（37.4%），其中 1,435,964 篇属于多个主题，形成 4,818,075 条论文—主题关系。

当前仍有 45,497 个词未逐项审核。完整词典已经提取，人工词表整理尚未覆盖全部长尾词。未命中只说明当前词典没有识别到，不能解释为论文与能源无关。覆盖率不等于召回率。

归类规则

  1. 使用全部冻结论文的完整来源关键词，保留低频词及原始分数为0的词。关键词来自来源数据/OpenAlex标签，不保证是作者提供的关键词。
  2. 按Unicode、大小写、连字符与空白规范化；只合并明确列出的同义词，保留括号内词义。通过原始关键词ID匹配，不做模糊子串匹配。
  3. 命中直接触发词，归入对应主题。具体技术的条件触发词须同篇有规定相关方向的直接能源词；通用方法、材料、经济等支撑主题接受任一直接能源词。allowed families见主题定义中的conditional_anchor_topics，空列表表示任一能源锚点。每篇取全部主题的并集；不设贡献阈值、不设主题上限。
  4. 学科大类和通用辅助词不单独触发。明确范围外词、规则筛出词、未审核词各自保留状态，不删除原始词或整篇论文。
  5. 原始分数保留作追溯，不作为归属置信度。共现满足规则不代表通用材料/方法一定是该论文的主要研究方向。

例如“Lithium-ion battery + Machine learning + Graphene”可同时归入电池、能源人工智能、能源材料结构三个主题；仅“Machine learning + Graphene”没有明确能源词，会留为待判断。

如何审阅和修改

先在浏览器选择主题查看触发词和论文证据，再在工作簿逐项审阅。建议优先处理高频待审词、直接词的多义性、条件词造成的额外主题。词表配置位于 final/energy-topic-identification/pipelines/keyword_dictionary/curation.py、curation_additions.py 和 refine_rules.py，分类程序为 classify.py。CSV是本次配置的产物，直接修改CSV不会自动更新规则；更改配置后按以下流程重新生成并重新验收。

已知边界

  • 源关键词错标或缺失时，这条路线仍会漏分或误分。题名/摘要未用于补词或强制回填。
  • “任一能源词 + 通用方法词”的共现规则会产生额外方法/材料标签。审阅结果提供具体例子，不能把程序校验通过当作语义准确率通过。
  • 语义抽查每主题2条，共142条关系；部分抽样用于迭代词典，非独立盲测、非专家验收，不足以推断总体准确率。样本及评语全部可查。
  • 当前为广义能源电力词典，含油气、供热、生物能源等；若业务仅保留电网特定范围，应审阅主题开关，而非物理删除论文。
  • 本次处理论文，不自动迁移专利/政策，没有重算趋势、热点和TRL/CRL。旧NMF文件保留并校验哈希一致。
