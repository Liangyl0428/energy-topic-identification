# v0.2.0 NMF500发布与实验

本次发布 OpenAlex 关键词 TF-IDF + MiniBatchNMF，以及论文BGE中心的专利/
政策余弦候选关联。交付对象仍是冻结样本，不是约512万条原始记录全量分类。

已运行 K=400/450/500/550/600 网格、seed29和80%训练样本稳定性；新增20组
选模偏好/并列容差敏感性、6项选择指标留一消融。后者是选模指标消融，
不是TF-IDF表示或编码器的模型消融。500满足“约500”的业务偏好，但并非
所有质量指标共同支持的唯一最优点；原权重、零并列容差时选择450。

详见 [实验报告](../assets/nmf500/experiments/REPORT.md)。轮廓系数为负，
关键词标签与BGE最近中心的一致性有限；不能声称这些主题在向量空间清晰分离。
80%样本稳定性实验达到迭代上限，报告保留该警告。

历史网格使用训练拟合W标签，交付下游对所有切分统一 `model.transform`，
训练标签改变1735篇，重建中心后专利646条、政策139条Top1改变。
本仓 `assets/nmf500/current_topic_catalog.csv` 是下游实际生效目录；
`current_confidence_thresholds.json` 是重新校准值。完整当前分类落地在
相邻 `energy-topic-hotspots/pipelines/nmf500/build.py`，不能混用网格拟合
中心与下游修正中心。保留原始选模脚本/网格记录用于审计，不将其冒充修正后指标。

python -m pip install -r requirements-nmf500.txt
