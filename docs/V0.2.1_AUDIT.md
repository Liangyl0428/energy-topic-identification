# v0.2.1 严格审查与修正

审查基线为v0.2.0；未改动外层采集项目。判断：旧版本可用于探索，不能视为已经验证准确率的主题分类系统。

## 已确认并修复

1. 主入口训练文献使用fit_transform的W，验证/近期文献使用固定H的transform；同样文本可能因所属时期走不同规则。下游此前自行修正，主入口仍会复现旧错误。现在各时期统一固定H、4096批大小推断。
2. 未正则化NMF中W/H可互相缩放而保持WH不变；直接比较W使Top1依赖组件尺度。当前H行范数6.65—21.39。改用`W[:,j] * ||H[j]||₂`，相当于在单位范数组件上比较重建贡献；它不是主题概率。
3. 无效或零向量会被强制分配最近中心，余弦并列排序不确定。现拒绝无效向量、校验活动中心，按主题ID稳定处理并列。
4. 论文域第10百分位过滤曾被混同于跨来源分类可信性。所有专利/政策的`needs_review`均为true，另外记录`similarity_filter_passed`；没有专利/政策专家金标准，不能估计准确率。
5. 旧网格缓存可能混入新推断；现检查推断版本并拒绝静默复用。选模还拒绝重复候选或缺失/非有限指标。

## 实测结果与边界

142,000篇冻结论文中30,359篇相对v0.2.0生产标签改变（21.38%）。重算仍采用已拟合的500组件H，未重新训练，也未假称重新选出最优K。N0069没有当前论文，目录保留其编号并明确`active=false`，不伪造第500个有用主题。

同步中心后，3,308条专利、1,061条政策的Top1相对v0.2.0生产结果改变，
详见`transfer_changes_v021.csv`；对照输入哈希记录于`CURRENT_INFERENCE_AUDIT.json`。

|当前独立验证指标|结果|
|---|---:|
|6,000篇抽样余弦轮廓系数|-0.07970|
|关键词标签与BGE最近中心Top1一致率|35.67%|

低间隔不是错误率；几何指标也不是专家准确率。多义词、通用方法和跨任务混合仍明显存在。
下游重新核读52个数值候选，不能把这些目的性样本用来估计全部499个活动主题的纯度。
真正的分类质量验收仍需要代表性盲标、独立复核及来源分别校准，代码修复不能替代这一步。

`assets/nmf500/current_validation_metrics.csv`和`CURRENT_INFERENCE_AUDIT.json`记录新指标。
`candidate_metrics.csv`、`selection.json`、`stability_metrics.csv`及选模消融是v0.2.0历史实验，
不得与新推断指标混用。旧轮廓为负、80%训练重拟合不收敛及事后并列容差问题仍如实保留。
