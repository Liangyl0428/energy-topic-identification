# 全量论文NMF与专利／政策分类

新增[独立全量实验与远端发布流程](FULL_EXPERIMENTS.md)：等待本轮基础计算完成后执行，不停止或重启现有任务。基础完成标记和包含实验、远端推送的最终完成标记分别记录。

本入口处理冻结快照的5,119,004条记录：4,831,088篇论文、281,295条专利申请和6,621条政策。完成状态以工作目录的`ALL_REPOSITORIES_COMPLETE.json`为准；文件不存在时不能声称全量交付已完成。

从5,520个已核验原始论文CSV提取OpenAlex关键词，按论文ID选择确定的快照，使用全部论文统计关键词文档频率并拟合IDF。保留完整关键词短语及ID，最低文档频率10，最高覆盖率50%；缺失score不捏造权重。对所有非零表示论文进行500组件MiniBatchNMF训练，每轮每篇参与一次，共5轮；训练记录列出实际文档访问数。这是指定粒度的全量拟合，未声称500为最优类别数或已达到全局最优。

全部论文使用冻结H统一推断，以`W[:, j] * ||H[j]||₂`比较归属。主题编号为F0001–F0500，与样本版N编号没有直接对应关系。零关键词向量保留未分配原因，不用文本匹配暗中补成NMF归属。

全部来源文本用同一BAAI/bge-m3模型、1024维、FP16推理后保存float32归一化向量。论文使用题名与摘要，最多2048 tokens；专利和政策沿用有界题名及正文头／中／尾视图，文本超长时有裁剪记录。全量指所有记录进入流程，不代表获取论文PDF全文或模型读取任意长政策全文。每个主题内全部已归类且有可用向量的论文求算术均值，再L2归一化。全部可用专利／政策对活动中心计算余弦，最高者为候选类别，保留Top3及差距。无可用文本保留未分配状态。候选关联均待语义核验。

模型使用全部年份，历史趋势只作回溯描述。新主题范围和专利／政策具体任务支持需要重新审阅，不继承旧主题人工结论；主题关联不会自动赋予TRL/CRL。


`in_progress_or_interrupted`只表示未获得全部完成标记，不凭旧进度文件推断进程仍存活。原始耗时较长的完整embedding处理可能持续数小时；代码更新、训练结束和全量交付完成是三个不同状态。

CPU阶段使用`.venv-hotspots`，编码阶段调用现有Python3.10 BGE CUDA运行时。全量文件留在`work/full_nmf500_20260926`，各阶段有进度和完成标记。正常中断后执行同一命令复用核验过的缓存。输出包括逐文档Parquet、模型、全量向量、关键词词表、中心、覆盖统计、主题目录和验证记录。紧凑结果由`publish_local.py`同步到三个仓库的`assets/full_nmf500`。

NMF乘法更新提供CuPy float32加速，使用与sklearn相同的无正则Frobenius更新、初始化和收敛容差；CPU/GPU数值等价测试覆盖推断及在线组件更新。缓存固定H乘积减少重复计算。没有CUDA依赖时可用CPU实现。保存模型所需类在`pipelines/full_nmf/fast_nmf.py`，加载时应将该目录加入Python模块路径。GPU和CPU会有浮点舍入差异，不承诺逐位一致。

BGE编码支持同权重、同FP16的ONNX图融合。`optimize_encoder.py`先在跨来源文本上核验原图和融合图输出；通过后可用`encode.py --optimized`或自动恢复入口。其接受条件为最小余弦大于0.999、平均余弦大于0.9999且至少300条文本，属于数值近似校验，不是语义准确率。已完成的原图缓存不丢弃；续跑部分记录实际执行方式，二者仅有浮点计算差异。`embeddings/EXECUTION_*.json`与分片审计保留执行来源。

最终分类文件逐片SHA-256登记在`ASSIGNMENTS_MANIFEST.json`；热点入口核对完整文件清单和哈希，成熟度入口核对分类摘要、验证报告与中心，禁止混用样本或旧版本产物。
