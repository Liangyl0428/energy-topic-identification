# 全量主题识别效果对比

本次新全量模型与历史结果使用共同文献、统一向量空间重新计算指标，不直接混用旧报告中的分数。所有报告均绑定当前全量分类摘要及输入文件 SHA-256。

## 比较范围

- 全量论文：本次 NMF500 与历史 486 父类、500 原始、750 平级、990 合并、1000 原始结果；逐条共同有效论文计算 CH、DBI、簇内余弦、中心重叠和簇大小分布。
- 历史 142,000 篇论文：另加入旧样本 v020/v021 的原始交付标签，不悄悄修正旧标签。
- 历史 12,000 篇验证文献：加入已有 LSA/语义/BGE 聚类、OpenAlex 关键词 NMF 和 NMF400/450/500/550/600 候选。以当前模型与每个方法的共同已分类文献进行成对对比；严格全方法交集仅作次要诊断。

所有几何比较分别在同一全量 BGE-M3 1024 维空间和旧 MiniLM PCA64 空间计算；不同空间不混排。旧聚类原本优化旧空间，因此提供两种视角，而不是挑有利空间。

## 指标与限制

- CH 通常越高越好；DBI 通常越低越好；簇内平均余弦和轮廓系数描述几何紧密度及分离度。
- 全量及142k组的余弦轮廓系数在同一共同集合中按3个固定种子各抽3,000篇；验证成对比较按1个种子最多抽2,000篇。抽样仅用于该诊断，不缩减训练或全量几何统计。
- 覆盖率包含未分类记录；Gini、最大簇占比、有效主题数用于描述集中程度，不代表均匀就是正确。
- ARI/NMI衡量不同分类结果的一致性，不是人工语义准确率。
- 关键词 NPMI 和前10词多样性在历史12,000篇统一OpenAlex二值词表上单独计算；使用文档共现而非滑动窗口。各簇按同一文档频次规则抽词，成对使用相同已分类文献。词表来源可能有利于关键词方法，结果不是全量NPMI。
- 当前模型使用全部年份，包含历史验证文献：这是回溯评测，不是独立留出验证。不同K和簇形状会影响几何指标，不能由一个分数宣称“语义最优”。
- 没有人工标准答案，不报告准确率、Precision/Recall/F1，也不把专利／政策候选归类当作语义正确性验证。

## 复现和交付

在完整工作数据可用的工作区，依次运行 identification 仓库的 pipelines/full_nmf/evaluate_topics.py 和 evaluate_coherence.py。环境见 requirements-full-nmf.txt；大型向量、原始文献和逐条分类不随Git发布。

紧凑结果位于 assets/full_nmf500/topic_evaluation/：REPORT.md、RESULTS.md、geometry.csv、silhouette.csv、coverage.csv、agreement.csv、keyword_coherence.csv、COHORTS.json、PROTOCOL.json、INPUTS.json及COMPLETE.json。发布前核验评测输入和输出哈希，三个仓库携带同一评测副本。

失败恢复入口 resume_delivery.py --resume-failed-and-push 仅处理尚未提交的失败发布；保留旧冻结配置，重新核验远端并冻结已授权修改。若存在部分提交或推送，不自动覆盖、回滚或强推。新v0.2.0仅在三个main分支均推送且远端SHA验证通过后创建。
