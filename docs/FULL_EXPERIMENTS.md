原有训练、编码和基础下游流水线不停止、不重启。本次另外启动独立后续任务，等待工作目录的 ALL_REPOSITORIES_COMPLETE.json，再核验全量覆盖和摘要哈希。

执行顺序：

1. 热点全量实验：全部500主题；评分成分和门槛逐项消融；每类1500次固定种子的±20%权重扰动；完整数量门槛敏感性；1/3/5年核心窗口、2/3/4年新兴背景及背景年留一；全量论文文本/贡献差距过滤，并重新计算机构、引用及分母。
2. 跨来源关联实验：论文、专利、政策来源消融；余弦与Top1–Top2间隔网格；共同2026日期窗口；政策文档留一。潜在关联为探索性数值线索，门槛未经人工标注校准。缺少新主题政策族标注及申请人多样性数据，不能假称已核验这两项，也不继承旧样本人工结论。
3. TRL/CRL实验：全部已有有界技术对象的来源、引文、观测留一；来源类型与判据支持消融；证据可用日期、主题Top1/Top3与余弦/间隔敏感性。实际重跑评估引擎，绑定全量主题中心产生的新映射；不直接给500个主题赋级。
4. 完成并校验[主题效果对比](TOPIC_EVALUATION.md)，包括共同论文上的几何指标、覆盖率、分类一致性，以及共同历史关键词上的NPMI／多样性。执行相关测试和发布校验，将紧凑实验结果写入三个仓库的 assets/full_nmf500。向量、原始语料和逐条大文件保留本地，不上传Git。
5. 提交三个仓库，并非强制推送既有 origin/main；逐仓库查询远端提交验证成功，记录三个commit ID。

所有实验都是固定本轮分类模型后的描述性诊断，不重新训练NMF，不是独立时间外测试，也不是人工语义准确率或专家成熟度评审。权重扰动区间不是统计置信区间。恒定分数下Spearman不定义，CSV留空。

## 发布保护

启动时记录本地HEAD、远端分支提交、明确批准的改动和非生成文件哈希。只接收这批代码与确定的生成结果；如果出现别人新增的改动、分支/HEAD变化、远端前进、测试失败或文件哈希变化，停止后续发布，不自动合并、不覆盖、不强推。启动时不创建真实发布提交或推送；仅检查推送权限（dry-run）。

三个仓库推送不是跨仓库原子事务。某个推送失败时保留逐仓库回执，不回滚已成功的仓库、不谎报全部成功，需要检查后继续。
