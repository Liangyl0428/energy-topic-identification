# 怎么看这份结果

建议先打开 [Excel](../results/750类平级目录与文献标签.xlsx) 的“类别目录”。这张表包含全部 750 个主题，每行一个，编号从 `C0001` 到 `C0750`。

## Excel 里有什么

| 工作表 | 用途 |
| --- | --- |
| 类别目录 | 看主题名称、总数量、论文/专利/政策数量，以及待复核数量 |
| 总览 | 看整个数据集的规模和处理情况 |
| 改标流向 | 看记录从原类别调整到了哪些类别 |
| 决定状态 | 看有多少记录沿用原标签、经过调整或进入待复核 |
| 质量隔离、文本质量 | 看哪些记录有文本质量问题，分别有多少 |
| 来源统计 | 看全部输入中论文、专利和政策的数量 |
| 待复核原因 | 看哪些问题还需要进一步判断 |
| 阅读说明 | 查看原交付时的阅读提示 |

Excel 中提供的是目录和汇总。每篇记录的详细标签保存在原项目的逐文档文件中，没有随本仓库上传。

## 三种“数量”有什么区别

类别目录中最容易混淆的是下面三列。

| Excel 列名 | CSV 字段 | 统计范围 |
| --- | --- | --- |
| 记录数 | `documents` | 当前分到这个主题的全部记录，包括撤稿和待复核记录 |
| 可统计记录数（非撤稿） | `countable_documents` | 从记录数中排除撤稿；仍可能含待复核记录 |
| 自动规则支持数（非撤稿） | `supported_documents` | 当前标签获得自动规则支持、非撤稿且不在待复核范围的记录 |

例如，`C0001`“电池与充电设施热管理”有 2,068 条记录，其中 1 条带撤稿标记，所以可统计记录数为 2,067。这个主题的自动规则支持数为 0，待复核记录数为 2,068。这说明本轮结果尚未为这些标签提供相应的自动规则支持，不能据此判断该领域没有研究。

自动规则支持也不等于人工逐篇确认。比较主题规模时，应使用同一列，并结合待复核数量判断结果的可靠程度。

## 整体结果

| 项目 | 数量 |
| --- | ---: |
| 输入记录 | 5,119,004 |
| 分配到研究主题的记录 | 5,111,081 |
| 因文本质量问题单独处理的记录 | 7,923 |
| 已归类且非撤稿的记录 | 5,107,604 |
| 获得自动规则支持且非撤稿的记录 | 475,158 |
| 待复核记录 | 2,758,621 |
| 相对最初分类调整了研究主题的记录 | 374,161 |
| 已清理文本的记录 | 14,156 |

5,111,081 条已归类记录加上 7,923 条质量隔离记录，正好是全部 5,119,004 条输入。每条已归类记录只计入一个当前主题。

待复核的 2,758,621 条记录中，2,755,875 条已经有当前类别，另外 2,746 条存在文本质量问题。因此，“已归类”和“待复核”有交集，不能把两者相加当成总数。

## 已经检查了哪些内容

本仓库的检查包括：750 个编号是否连续、每个主题的来源数量能否加总、全局统计是否一致、Excel 与 CSV 是否对应，以及文件是否与记录的校验值一致。最新检查结果见[发布校验记录](../provenance/RELEASE_VALIDATION.json)。

原项目还检查过完整逐文档数据的行号、标签对应关系和清理文本，历史记录保存在[原始验证报告](original/VALIDATION.json)中。完整逐文档文件没有上传，这部分检查未在本精简仓库重新运行。

如果要进一步判断某个主题的分类质量，需要结合该主题下的真实文本进行审阅。这里的数量与文件一致性检查不提供整体分类准确率。
